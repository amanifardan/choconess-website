# Choconess

Choconess is a homemade chocolate business offering handcrafted treats and gift boxes. Customers can explore the menu and get in touch or place an order through WhatsApp.

This website is built with HTML, CSS and JavaScript. The `static` folder contains the styles, scripts and images.

Brand colors: `#8FB8BC`, `#E0F2F4`, `#01464D` and `#710100`.
